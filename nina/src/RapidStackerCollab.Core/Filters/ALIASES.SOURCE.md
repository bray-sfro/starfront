`aliases.json` in this folder is a verbatim copy of `worker/crates/filters/aliases.json` from the `m1-filters` branch of
this repository, commit `3f43dfac386e57868d9cf3fbc0dbab6ca1f637b0` (`fix(filters): track the collab-filters CLI source`),
schema `collab-filters/aliases` version 1, table version 1. It is generated by
`collab-filters export-aliases`; **do not edit it here**. Refresh it by copying the file again after the crate's
table changes. It is embedded in `RapidStackerCollab.Core` as the offline fallback; the plugin prefers the table
published at `/public/filters/aliases.json`. The conformance test
(`tests/RapidStackerCollab.Core.Tests/FilterNormalizerTests.cs`) fails if this copy and the crate's drift apart whenever
the crate is present in the checkout.
