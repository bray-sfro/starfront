The Starfront installers the server offers at /download.

Put Starfront-Setup-<version>.exe here (packaging\build.ps1 copies the one it
builds here itself) and run the deploy cmd. The newest version in the folder
is the download; older ones are not listed but their links keep working.
The installers are not in git; this note is. Only the newest one needs to
stay here; an older one can be deleted once nobody links to it.
