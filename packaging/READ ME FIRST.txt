Starfront
=========

Telescope control and collaborative imaging for Windows.

Install
-------
1. Unzip this folder anywhere you like - e.g. C:\Starfront.
   Keep everything together; the program looks beside itself for its files.
2. Double-click  Starfront.exe.
   Windows may say it protected your PC the first time: More info -> Run anyway.
3. The window opens on its own. Your settings, targets and plans live in
   C:\Users\<you>\Starfront (C:\Users\<you>\AstroControl on a PC that ran an
   earlier build), so replacing this folder with a newer one never loses them.

Windows 10
----------
The window is Microsoft Edge WebView2. Windows 11 has it; a Windows 10 PC
that has not had Edge updated may not. If Starfront says it could not open
its window, install the WebView2 Runtime (Evergreen, x64) from
   https://developer.microsoft.com/microsoft-edge/webview2/
and start Starfront again. Until then it offers to open in your browser.
It also needs the .NET Framework 4.7.2 or later, which Windows Update has
put on every Windows 10 PC for years.

Coming from N.I.N.A.?
---------------------
Equipment... -> Import from N.I.N.A.  reads the profile you last used and
brings across your optics, camera, filters and offsets, focus and dither
settings, ASTAP, and which driver is in which slot. It shows everything before
it writes anything.

Joining the collaboration
-------------------------
Collab tab -> Join with Discord. One button: it signs you in with Discord and
enrols this telescope. You need to be a member of the Discord server.

Staying on N.I.N.A.?
--------------------
There is a plugin instead. In N.I.N.A., Options -> General -> Plugin
Repositories, press + and enter
   https://collab.starfront.space/nina
then install "Starfront Collaboration" from the Plugins tab and restart.
Sign in with Discord on its options page, fill in your exposures, join a
collaboration from the Starfront panel on the Imaging tab, and put the
"Starfront collaboration" container in your Advanced Sequence where a target
would go. It needs N.I.N.A. 3.2 or later.

You will also want
------------------
- The ASCOM Platform (ascom-standards.org) and your drivers - as for N.I.N.A.
- ASTAP (hnsky.org/astap.htm) with a star database, for plate solving.
- PHD2 (openphdguiding.org), for guiding.
- Microsoft Edge WebView2 - already on Windows 10/11; if the window does not
  open, install it from microsoft.com/edge/webview2.

If something goes wrong
-----------------------
The log is  C:\Users\<you>\Starfront\logs\astrocontrol.log  (or under
AstroControl on a PC that ran an earlier build).
"Starfront Console.exe" runs the same program with a console, so a window that
will not open says why:   "Starfront Console.exe" --browser   opens it in your
browser instead.

The full manual is README.md in the _internal folder, and is the same text as
the project's README.
