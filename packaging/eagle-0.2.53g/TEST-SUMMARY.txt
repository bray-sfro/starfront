Roof closed rule — where it is enforced
----------------------------------------

  astrocontrol/roofguard.py
      needs_closed_roof     bias, dark, darkflat, panel flat (not sky flat)
      begin / end           held for the whole closed-roof set
      blocked               the reason an open must be refused
      request_open          raises before dome.open_shutter
  astrocontrol/calibrating.py
      CalibrationRunner._set_on_rig        holds the guard
      CalibrationRunner._shoot_set         re-checks the roof before frames
      CalibrationRunner._require_roof_closed
          closing: hold until closed or 30s, then abort
          open, opening, error, anything else: abort, no frames
          never calls OpenShutter
      CalibrationRunner._require_cover_closed
          a cover that exists must read closed
      CalibrationRunner._one_filter        cover check after the cover is shut
  astrocontrol/main.py
      dome_shutter          409 if blocked(), before open_shutter
  astrocontrol/sequencer.py
      Sequencer._ensure_roof_open   calls request_open, not open_shutter
  astrocontrol/devices/ascom.py    AscomDome.open_shutter
  astrocontrol/devices/alpaca.py   AlpacaDome.open_shutter
      both raise before the driver is asked

Follower exclusion
------------------

  Not the capture folder. The gate is astrocontrol/autoupload.py
  follower_frame / refuses_upload / allows_upload:

    role == "follower"                         default: do not upload
    colour / Bayer / instrument contains 6200MC, and not the master
    camera.uploadCollab False is an explicit off
    camera.uploadCollab True is an explicit opt-in (the tandem leaves it unset)
    a missing identity is not treated as a follower (older rows still report)

  Live lights: Capture.upload_identity() (role, rig id, camera name, Bayer)
  passed to AutoUploader.light_saved. A follower is not queued.
  AutoUploader.send refuses a follower item even if it was forced onto the
  queue, and does not call the server.

  Backfill: AutoUploader.backfill reads headers only. Project and task come
  from the target whose name matches the capture folder or TARGET/OBJECT.
  They are stored on the queue item. The file is not rewritten.
  The 14 FSQ85 lights of 2026-11-05 with a blank PROJID match
  project 97fcae827a9f, task 481536614589. The 27 Rokinon lights do not queue,
  including one placed in the FSQ85 folder. A master frame placed in the
  Rokinon folder still queues.

  Session report: targets.add_panel_integration keeps a follower on its own
  byTelescope slice and does not add those seconds to the tally that is
  reported. collabclient.CollabClient.report_pending drops that slice and
  does not POST it. A report that is sent includes instrument and that
  camera's focalLength.

  tools/check_follower_quiet.py: follower not queued, not sent, and a
  12.25 h Rokinon L row is absent from the report. The FSQ85 row is sent
  as 300 s with instrument ZWO ASI6200MM Pro and focalLength 455.
